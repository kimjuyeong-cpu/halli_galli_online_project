# HALLI GALLI ONLINE

2~4명이 각자 브라우저에서 방 코드로 접속하는 실시간 웹게임 시작 프로젝트입니다.

## 실행 방법
1. 컴퓨터에 Node.js 18 이상을 설치합니다.
2. 이 폴더에서 터미널을 열고 `npm install`을 실행합니다.
3. `npm start`를 실행합니다.
4. 브라우저에서 `http://localhost:3000`에 접속합니다.

## 여러 컴퓨터에서 함께 접속하기
실제 멀티플레이를 하려면 이 프로젝트를 인터넷에 공개된 Node.js 호스팅 서비스에 배포해야 합니다. 배포 후 생성된 HTTPS 주소를 참가자들에게 공유하면 각자 접속할 수 있습니다. 같은 와이파이에서 시험할 경우 호스트 컴퓨터의 내부 IP와 방화벽 설정이 필요합니다.

## 현재 구현
- 방 생성 및 6자리 코드
- 2~4명 입장, 방장 시작
- 56장 과일 카드 구성 및 자동 배분
- 순서대로 카드 공개
- 공개 카드의 과일 합계가 정확히 5개면 종을 눌러 카드 획득
- 오답 종 벌칙, 점수 및 종료 처리
- 실시간 상태 동기화(Socket.IO)

## 참고
이 코드는 실제 온라인 접속이 가능한 출발 프로젝트입니다. 서버가 실행되는 동안에만 방과 게임이 유지됩니다. 브라우저를 새로고침하거나 연결이 끊겼을 때 진행 중인 게임을 복구하는 기능, 관전자/재접속 기능, 공식 규칙의 세부 벌칙 및 장시간 플레이 검증은 추가 개발이 필요합니다. 상업적 배포 전에는 할리갈리 상표·디자인·카드 이미지 등 지식재산권을 별도로 확인하고, 독자적인 게임명과 그래픽을 사용하는 것을 권장합니다.
